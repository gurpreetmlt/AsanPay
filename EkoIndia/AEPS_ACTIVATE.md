# Activate AePS Fingpay for Agent API Reference

`PUT https://staging.eko.in/ekoapi/v3/admin/network/agent/{user_code}/aeps-fingpay/activate`

Enable AePS Fingpay service for your agent by submitting their biometric device details and KYC documents.

This API enables an agent (identified by their `user_code`) to use the AePS Fingpay service. It accepts the agent's biometric device model, serial number, settlement account, address proofs, and KYC documents (PAN card, Aadhaar front and back) as a multipart form submission. After submission, the activation enters a 'pending' state and is approved within 2–3 business days. Only activated agents can perform AePS transactions. File uploads must be JPEG/JPG/PDF format, each under 1 MB; PNG is not accepted.

> [!IMPORTANT]
> This is **not** a form field per parameter. Every non-file field below travels together as one JSON object in a single form field named `form-data`, and each document is its own file part (`pan_card`, `aadhar_front`, `aadhar_back`).

> [!NOTE]
> This API must be called after onboarding your agent using the **Onboard User API**.

> [!WARNING]
> The approval may take 1-2 business days.

> View product & pricing details: [AePS Cashout](https://eps.eko.in/products/aeps-api.md)

## Path parameters

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| user_code | string | yes | Unique code of the agent for whom AePS Fingpay service is being activated. e.g. 20810200 |

## Body parameters

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| initiator_id | string | yes | Registered mobile number of the API user (see Platform Credentials). e.g. 9962981729 |
| client_ref_id | string | no | Unique reference ID per API call, generated by your system (max 20 characters). e.g. 2026010100123456789 |
| modelname | string | yes | Model name of the UIDAI-certified biometric device (e.g. Morpho 1300E3, Mantra MFS100). |
| devicenumber | string | yes | Serial number of the biometric device. e.g. SN1234567890 |
| account | string | yes | Bank account number for AePS settlement. |
| ifsc | string | yes | IFSC of settlement account branch (11 chars). |
| shop_type | string | yes | Shop-type ID as string. Use Get Shop Types API. e.g. 4215 |
| office_address | object | yes | Nested JSON: line, city, state, state_id, pincode. See Get States for state_id. |
| address_as_per_proof | object | yes | Address as on proof doc. Same keys as office_address. |
| aadhar | string | yes | 12-digit Aadhaar number (plaintext on this API — not RSA unlike Daily KYC). |
| pan_card | file | yes | PAN card. JPEG/JPG/PDF, max 1 MB. PNG not accepted. |
| aadhar_front | file | yes | Aadhaar front. JPEG/JPG/PDF, max 1 MB. |
| aadhar_back | file | yes | Aadhaar back. JPEG/JPG/PDF, max 1 MB. |
| latlong | string | yes | GPS `latitude,longitude`. e.g. 28.6139,77.2090 |

## Headers

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| developer_key | string | yes | Static API key. |
| secret-key | string | yes | base64(HMAC-SHA256(timestamp, base64(access_key))). |
| secret-key-timestamp | string | yes | Unix ms timestamp matching secret-key. |
| content-type | string | yes | multipart/form-data — let HTTP client set boundary; do not hardcode. |

## Response

| Field | Type | Description |
| --- | --- | --- |
| status | number | 0 = success |
| message | string | Human-readable message |
| response_status_id | number | Granular status; shared error-codes table |
| response_type_id | number | Response shape id |
| data | object | Payload |
| data.service_status_desc | string | e.g. pending / Activated |
| data.service_status | number/string | State id of activation |

## Response types

| response_type_id | Meaning | Next step |
| --- | --- | --- |
| 1259 | AePS Registration Successful | (doc links DMT onboard — product-specific) |
| 1297 | User does not exist | Onboard User first |

## Example request (`form-data` part)

Sent as `multipart/form-data`: this JSON is the value of a single form field named `form-data`; uploads are separate parts.

```json
{
  "initiator_id": "9962981729",
  "client_ref_id": "2026010100123456789",
  "modelname": "Morpho 1300E3",
  "devicenumber": "SN1234567890",
  "account": "38759149196",
  "ifsc": "SBIN0007515",
  "shop_type": "4215",
  "office_address": {
    "line": "Middle Tarku Near Secondary School",
    "city": "Singtam",
    "state": "Sikkim",
    "pincode": "122002",
    "state_id": "23"
  },
  "address_as_per_proof": {
    "line": "Temi Tarku Secondary",
    "city": "Gurgaon",
    "state": "Haryana",
    "pincode": "122002",
    "state_id": "23"
  },
  "aadhar": "123456789012",
  "latlong": "28.6139,77.2090"
}
```
